# fa-200 — مجموعه‌تست فارسی

هدف: ۲۰۰ صفحه فارسی (۶۰ خبر، ۴۰ بلاگ، ۴۰ محصول، ۳۰ لندینگ/خدمات، ۳۰ انجمن) با متن اصلی برچسب‌خورده.

## روش ساخت
1. `python -m bench.collect --dataset fa-200` — منابع در `bench/sources.yml`؛ URLها از sitemap یا صفحه فهرست کشف و با کش filbert دریافت می‌شوند.
2. برچسب **auto**: متن با selectorهای مخصوص هر سایت (مستقل از استخراج‌گرهای filbert) ساخته می‌شود. کیفیت آن به selector وابسته است و باید بازبینی شود.
3. برچسب **gold**: بازبینی دستی با `python -m bench.label fa-200 <id>` (صفحه HTML با تیک بلوک‌ها → دانلود `txt`/`json` → کپی در `gold/` → `--promote`).
4. **unlabeled**: selector چیزی نداد (اغلب صفحات JS-رندر)؛ فقط برای تست سرعت/پایداری استفاده می‌شوند و در F1 نمی‌آیند.

`index.jsonl` وضعیت هر صفحه را دارد. bench فقط روی `gold` و `auto` اجرا می‌شود؛ در گزارش، سهم هر وضعیت نوشته می‌شود.

## وضعیت (2026-11-03)
۲۰۲ صفحه با ابزار آنلاین بازبینی دستی شد: ۲۰۰ gold، ۲ نامطمئن (`auto` + پرچم review). برچسب‌های خام در `labels/`؛ `python -m bench.promote_labels` آن‌ها را به `gold/` و `index.jsonl` اعمال می‌کند.
