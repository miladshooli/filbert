پرسش‌های متداول

هر کاربر اپلیکیشن والکس می‌تواند با مراجعه به بخش «مدیریت API» در منوی «حساب کاربری» حداکثر سه API Key بسازد.

کسانی که به API Key افشا شده دسترسی دارند به تمام اطلاعاتی که در والکس دارید، دسترسی دارند؛ اما «برداشت» و «انجام معاملات» تنها در صورتی در دسترسند که در زمان ساخت API Key امکان «معامله» و «برداشت» توسط کاربر فعال شده باشند. در هر حال، محافظت از API Key برعهده‌ی کاربر است و ما توصیه می‌کنیم آن را در اختیار کسی قرار ندهد، و اقدام به حذف کلید افشا شده نماید. همچنین شما می‌توانید با تعریف IP اختصاصی امنیت API Key خود را افزایش دهید.

علی‌رغم تلاش شبانه‌روزی تیم زیرساخت برای بهبود و نگهداری سایت والکس، گاهی سرویس‌ها در دسترس نخواهند بود و در سریع ترین زمان مشکل رفع خواهد شد. در‌نتیجه برای خطای ۵۰۴ در حال حاضر نیاز است تا مشتری برای درخواست در فرصت دیگری تلاش مجدد کند.
